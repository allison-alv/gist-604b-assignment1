## Understanding Git Workflow
Explain in 2–3 sentences the difference between:
- Local workspace (Codespace)
- Remote repository (GitHub.com)
A local workspace, such as a Codespace, is your active development environment where you write, run, and test your code. A remote repository on GitHub acts as the centralized cloud storage hub that securely stores your project's version history and facilitates team collaboration. You write and test your code locally in the workspace, then push your changes up to the remote repository for sharing and safekeeping.
