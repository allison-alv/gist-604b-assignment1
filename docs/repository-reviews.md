## Reflection    

In 3–5 sentences, explain what you learned about how open source projects are organized.  
By reviewing these repositories, I learned that open source projects can be structured in very different ways depending on what they are meant to do, ranging from a single detailed README to massive multi-folder codebases like QGIS. I realized that super detailed READMEs are really the gold standard in open source because they act as the landing page, documentation, and user manual all in one spot. Having folder-level READMEs also makes navigating complex repositories a lot easier. Finally, looking at activity levels showed me that even if a repository isn't actively updated anymore, it can still be a useful reference tool if the content is well-organized and hyperlinked.
